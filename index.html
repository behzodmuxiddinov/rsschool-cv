Code Example

Codewars kata Descending Order (7 kyu). The function takes a non-negative number and rearranges its digits so that they go from the largest to the smallest.

function descendingOrder(n) {
  return Number(
    String(n)
      .split('')
      .sort((a, b) => b - a)
      .join('')
  );
}

descendingOrder(0);           // => 0
descendingOrder(15);          // => 51
descendingOrder(1021);        // => 2110
descendingOrder(123456789);   // => 987654321
